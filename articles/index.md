# Articles

### Getting started

An introduction to the dlnmLPS package for fitting distributed lag
non-linear models (DLNMs) within a Bayesian framework using Laplace
approximations. This article provides a step-by-step introduction to
installing and loading the package, fitting a basic DLNM using
unpenalized splines, and extending the model to penalized spline
representations. It also illustrates how to account for smooth covariate
effects and incorporate spatial and temporal random effects into the
model.

spatially varying DLNMs, effect-modified DLNMs, and bivariate (joint)
DLNMs, illustrating its flexibility in modelling complex
exposure-lag-response relationships.
